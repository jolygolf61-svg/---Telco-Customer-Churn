## Бизнес-задача
Оценить экономику подписочной модели (LTV, CAC, срок окупаемости) и понять,
какие сегменты клиентов прибыльны, а какие убыточны при текущей стоимости
привлечения — на примере данных телеком-компании, интерпретированных как
подписочный сервис.

## Данные
- Источник: Kaggle, Telco Customer Churn (IBM), 7043 клиента (7032 после очистки)
- Реальные данные из датасета: срок обслуживания клиента, ежемесячный платёж,
  тип контракта, интернет-услуга, способ оплаты, факт оттока
- Допущения (не из датасета, заданы отдельно и обоснованы бенчмарками рынка):
  CAC = 3500 ₽ (интерактивный параметр, диапазон 500–8000 ₽),
  себестоимость обслуживания = 30% от ежемесячного платежа

## Методология
- Доля оттока = доля клиентов с признаком "Отток = Да"
- Пожизненная ценность клиента (LTV) = средний чек × (1 / доля оттока)
- Отношение LTV к CAC — интерактивный расчёт через параметр в Power BI
- Точка безубыточности по CAC = LTV сегмента (CAC, при котором LTV:CAC = 1)
- Срок окупаемости = CAC / (средний чек × валовая маржа)

## Ключевые выводы

**1. Вся клиентская база убыточна при текущем CAC.**
При CAC = 3500 ₽ отношение LTV к CAC по всей базе — 0,07. Ни один сегмент
по типу контракта не достигает безубыточности (LTV:CAC = 1):
Помесячно — 0,04, Год — 0,16, 2 года — 0,61.

**2. Разброс по точке безубыточности — в 14 раз.**
Максимальный CAC, при котором клиент окупается:
- Помесячно — 155 ₽
- Год — 577 ₽
- 2 года — 2 137 ₽

При текущем CAC компания может позволить себе тратить на привлечение
помесячного клиента не более 155 ₽, чтобы выйти в ноль — то есть
маркетинговый бюджет на этот сегмент завышен более чем в 20 раз.

**3. Отток концентрируется в первый год обслуживания.**
Доля оттока по сроку обслуживания: 47,7% (0–12 мес) → 28,7% (13–24 мес) →
20,4% (25–48 мес) → 9,5% (49+ мес). Показатель почти линейно снижается
по мере увеличения срока жизни клиента — новые клиенты представляют
наибольший риск, и этот риск совпадает с сегментом помесячных контрактов
(42,7% оттока).

**4. Худшая комбинация сегментов — оптоволокно + электронный чек.**
В разрезе интернет-услуги и способа оплаты максимальный отток — у клиентов
с оптоволоконным интернетом, оплачивающих электронным чеком (53,2%),
что более чем в 7 раз выше, чем у клиентов DSL с оплатой картой (12,1%).

## Рекомендации бизнесу
- Пересмотреть CAC для помесячного сегмента либо стимулировать переход
  на годовые/двухгодичные контракты (снижением цены или бонусами) —
  это кратно улучшает LTV:CAC
- Усилить удержание именно в первые 12 месяцев (онбординг, ранние офферы
  на доп.услуги) — здесь риск оттока максимален
- Отдельно разобрать причины повышенного оттока в сегменте
  оптоволокно + электронный чек (например, проблемы с автосписанием
  или качеством услуги)

## Ограничения анализа
- CAC (3500 ₽) и себестоимость (30%) — гипотетические допущения,
  не фактические данные компании
- Выручка — статический снимок базы на момент выгрузки, а не помесячная
  динамика во времени (для полноценной когортной динамики потребовались бы
  данные с датами подключения клиентов)
- Точка безубыточности по CAC не учитывает возможное изменение оттока
  при снижении затрат на привлечение (упрощение модели)
